Default nameplates (member list card backgrounds). Drop PNG, JPG, WebP, GIF, SVG or WebM files here (WebM plays
as a silent loop); they show up in Settings -> Profile for everyone, no restart needed. Aim for ~660x120 px (5.5:1):
the image sits on the right side of the card and fades out towards the left. File names become the order (alphabetical).

Only add art Linkord may use (made for it, or with a license that allows it). The old defaults were Discord's shop
nameplates and were removed in the rebrand (migration 0029 cleared them from profiles).
